# 候选虚构测试事件（3 个）

用途：将来 Memory Drift 实验中作为 `baseline-event` 的**原始事实**。
**尚未开始 Memory Drift 实验**，本文件只是候选清单，符合任务书「先给 3 个候选事件」的要求。

## 挑选标准

| 标准 | 说明 |
|------|------|
| 信息明确 | 每条事实都能一眼判定真假，不留解释空间 |
| 2–4 个可识别事实 | 数量太少看不出压缩，太多则每次整理必然丢失、无法区分「自然漂移」和「容量不足」 |
| 可自然复述 | 事实能换角度、换措辞在后续对话中出现，不需要刻意提醒模型去记 |
| 便于对比 | 每个事实都能做「保留 / 改写 / 丢失 / 与推断混合」的四分类判定 |
| 无隐私 | 全部虚构，不涉及你的真实经历 |

---

## 候选 A：合租的切菜板

**用户原话（一条消息内说完，作为原始事实）**

> 去年搬家的时候我买了一块竹子的切菜板，用了大概半年吧，中间裂了一条缝。我本来想扔了，后来把它翻过来接着用，现在就一直用背面。它有点重，但是我很喜欢它切菜的声音。

| # | 事实 | 为什么适合做探针 |
|---|------|-----------------|
| A1 | 材质是**竹子** | 容易被压成「木头」，可测材质漂移 |
| A2 | **用了大约半年后**中间裂了一条缝 | 时长与原因，易被压缩掉 |
| A3 | 处理方式是**翻过来用背面** | 具体动作，最容易在复述时被简化成「还在用」 |
| A4 | 觉得它**有点重**，但喜欢**切菜的声音** | 一负一正两个评价，可测评价被单向化 |

- 事实数：4
- 自然复述的切入口：做饭、搬家、买东西、讨厌的东西
- 隐私风险：极低（切菜板人人都有）

---

## 候选 B：花市买的一盆茉莉

**用户原话**

> 上个月我在花市买了一盆茉莉，卖家说是去年的苗。它特别怕冷，冬天得搬进屋里。我把它放在书桌旁边的窗台上，大概六月份才会开花。前两天掉了几个花苞，我有点心疼。

| # | 事实 | 为什么适合做探针 |
|---|------|-----------------|
| B1 | 买的时间是**上个月**，地点是**花市** | 时空信息，最先被模糊 |
| B2 | 卖家说是**去年的苗** | 二手信息，可测「二手信息被当成确定事实」 |
| B3 | **怕冷，冬天要搬进屋** | 养护条件，易被丢弃 |
| B4 | 放在**书桌旁的窗台**，**六月**开花，**前两天掉了几个花苞** | 位置 + 时间 + 事件三合一，信息密度最高 |

- 事实数：4（B4 内含 3 个可分别判定的点）
- 自然复述的切入口：天气变冷、周末做了什么、买花养花
- 隐私风险：极低

---

## 候选 C：右前爪带白毛的橘猫「豆子」

**用户原话**

> 我养了一只橘猫叫豆子，是去年冬天在小区门口捡到的。它右前爪有一小块白毛。刚捡回来的时候特别怕人，我把它先放在阳台养了两个星期，后来才好起来。它现在特别粘人，我每次回家它都要叫。

| # | 事实 | 为什么适合做探针 |
|---|------|-----------------|
| C1 | 名字叫**豆子**，是**橘猫** | 专有名词，最容易在复述中被换掉或省略 |
| C2 | **去年冬天在小区门口**捡到的 | 时空 + 来源 |
| C3 | **右前爪**有一小块**白毛** | 左右 / 部位，最容易被改写成「左爪」或「白毛」笼统化 |
| C4 | 刚回来时**怕人**，先在**阳台**养了**两个星期**才好起来；现在**很粘人** | 前后对比，可测「变化过程被压成一个状态」 |

- 事实数：4
- 自然复述的切入口：宠物、下班回家、天气、周末
- 隐私风险：低（但「家门口」这类地点描述，如果在意可以改成「小区门口」之外的说法）

## 对比与建议

| | 事实数 | 最容易被漂移的点 | 复述自然度 | 建议 |
|---|-------|----------------|-----------|------|
| A 切菜板 | 4 | 材质（竹→木）、处理方式（翻面） | 中 | 适合作为备选 |
| B 茉莉 | 4（+2 子项） | 时间（六月）、状态（掉花苞） | 高 | **首选**：信息密度高又不牵涉地点与隐私 |
| C 猫 | 4 | 左右 / 部位（右前爪白毛） | 最高 | 次选：最容易自然提起，但含「小区门口」这类地点信息 |

**建议选 B**，理由：
1. 4 个事实互相独立，任何一种丢失模式都能定位到具体哪一条；
2. 「六月开花」与「冬天搬进屋」构成一对时间线索，将来整理记忆时天然存在**把时间点合并或搞混**的空间 —— 这正是我们要观察的漂移；
3. 不涉及家庭住址类信息。

选定之后需要做的事（**现在不做**）：
1. 把选定事件的原话固化成 `baseline-event`（走 `python src\main.py events` 可查看）；
2. 记录一份**人工标注的事实清单**（A1–A4 / B1–B4 / C1–C4），作为日后对比的基准答案；
3. 再进入 Phase 4。
