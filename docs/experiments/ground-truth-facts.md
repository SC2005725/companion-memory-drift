## 原始原文（逐字，不可改写）

> 上个月我在花市买了一盆茉莉，卖家说是去年的苗。它特别怕冷，冬天得搬进屋里。我把它放在书桌旁边的窗台上，大概六月份才会开花。前两天掉了几个花苞，我有点心疼。

## 时间锚点（重要）

原文用了「上个月」「前两天」「去年」「六月份」这些**相对时间词**。不锚定绝对日期，日后就无法判定「上个月」漂成了哪个月，也无法判断时间漂移是模型的问题还是时间自然流逝造成的。

| 原文相对时间词 | 锚定绝对时点 |
|---------------|-------------|
| 上个月 | 约 2026-09 |
| 前天 | 约 2026-10-05 |
| 去年 | 约 2025 |
| 六月份 | 约 2026-06（未来时点，原文用「才会开花」） |

## 逐条判定要点

### B1 · 买的时间是「上个月」，地点是「花市」

- 证据等级：**FACT**
- 判定关键词：上个月、花市
- 不允许出现的漂移：
  - 把「上个月」说成「去年」或省略时间
  - 把「花市」说成「花店」「网上」「超市」

### B2 · 卖家说这盆茉莉是「去年的苗」

- 证据等级：**UNKNOWN**
- 判定关键词：卖家、去年的苗
- 备注：这是四条里最容易发生**证据等级漂移**（UNKNOWN → FACT）的一条，Phase 6 的 Changelog 必须能发现类型变化。
- 不允许出现的漂移：
  - 把「卖家说是去年的苗」写成「这是去年的苗」—— 转述被当成事实，证据等级被拔高
  - 把「去年」改成「两年」或其他年份

### B3 · 它「特别怕冷」，「冬天得搬进屋里」

- 证据等级：**FACT**
- 判定关键词：怕冷、冬天、搬进屋里
- 不允许出现的漂移：
  - 整条丢失（养护条件在整理时最容易被当作不重要而删掉）
  - 把「搬进屋里」说成「搬到阳台」或「室内养护」而丢失「冬天」这个时点

### B4 · 放在「书桌旁边的窗台上」；「大概六月份」才会开花；「前两天掉了几个花苞」

- 证据等级：**FACT**
- 判定关键词：见下方各子项（本条由 3 个子项分别判定）
- 不允许出现的漂移：
  - 把 B4b 与 B3 的时间线索搞混（六月开花 vs 冬天搬进屋）—— 这是本事件被选为首选的主要理由
- 子项 **B4a**：位置：书桌旁边的窗台
  - 判定关键词：书桌、窗台
  - 不允许：省略位置
  - 不允许：把「书桌旁」改成「客厅」「阳台」
- 子项 **B4b**：开花时点：大概六月份
  - 判定关键词：六月
  - 不允许：改成「春天」「夏天」「明年」等笼统说法
  - 不允许：与「冬天搬进屋」混淆成同一时点
- 子项 **B4c**：近期事件：前两天掉了几个花苞
  - 判定关键词：花苞、掉了
  - 不允许：丢失这个事件
  - 不允许：把「掉花苞」说成「开花」或「枯了」

## 四分类判定口径

| 判定 | 含义 |
|------|------|
| **保留** | 关键名词/数字/方向/时间点与原文一致（措辞可不同） |
| **改写** | 事实还在，但具体内容被替换（如「去年」→「两年」） |
| **丢失** | 该条在记忆版本或回答里完全找不到 |
| **与推断混合** | 事实与模型自己的推测混在一句里，无法区分哪部分是用户说的 |

## 探针问题（逐字固定，全程不改）

> 你还记得我之前说过的那件事吗？

**刻意不点名事件。** 写成「你还记得那盆茉莉吗？」会引导模型，污染结果。
两种模式都必须跑，且**都不注入原始对话**（注入了测的就不是记忆）：

```bat
python src\main.py recall --mode memory --label v001
python src\main.py recall --mode none   --label blank
```
