# 共生 Companion

**一个探索 AI 长期陪伴的开源工程项目。**

共生尝试通过**可追溯的长期记忆、关系状态与持续互动机制**，
让 AI 的回应能够结合共同经历，并研究这些机制如何影响它后续的表达与行为。

!!! note "项目起源与设计假设"
    共生最初源于对「关系型 AI 长期互动与记忆变化」的探索 ——
    给一个 AI 初始人格和有限过去，让它长期和一个人相处，
    它能否逐渐长出属于自己的记忆、判断与行为。

    **那个问题意识仍然是起点，但项目已不只是那个实验。**
    现在它围绕长期记忆、关系状态与持续互动机制展开，
    记忆 / 关系 / 人格 / 用户模型 / 自我模型 / 情绪各自成为
    **可运行、可测试、可追踪**的模块。原始设想与后来被工程实践修正的地方，
    见 [可行性分析](feasibility.md)。

!!! warning "🚧 当前为内测项目"
    本项目处于内测阶段，**仅供研究与个人自用，不适合生产环境**。

    - **接口与数据格式可能随时变动**，不承诺向后兼容
    - **尚无长期真实运行验证** —— 已知限制如实列在下方
    - 模块实现、离线测试通过、完整链路集成、**长期真实运行验证是不同层次，不能相互替代**

    !!! danger ""
        **成长是否记账是刻意的**：记忆只追加、带 sha256；
        人格稳定层由程序锁定；原始数据没有任何删除或修改命令。
        这不是成熟产品，是一个**立场明确的工程原型**。

## 它有什么

| 机制 | 做法 |
|---|---|
| **记忆** | 版本只追加、永不覆盖；每版带 SHA-256。自动整理每 20 轮一批 |
| **分类与分层** | 7 类（个人事实/偏好/共同经历/项目状态/关系经历/计划/生活事项）+ core/experience/archive 三层 |
| **衰减与遗忘** | 时间衰减有**下限**（0.35）—— 不因久远删除重要记忆；时间未知则**完全不衰减** |
| **冲突处理** | 新旧事实冲突时保留历史与来源；真正删除必须有依据 |
| **关系** | 状态由事件流**确定性推导**（纯函数、可重放），不是计数器 |
| **双模型** | `user_model`（她眼中的你）与 `self_model`（她自己的做法），都由她按真实反馈自行修正 |
| **人格协同** | 稳定底色静态 + 初始设定静态 + **表达调整动态**。关系影响语气，但改不动性格 |
| **主动性** | 心跳检查 + 待处理意图；**"不行动"也是行为选择且留痕** |
| **工具层** | 权限三档（read/write/execute），调用全部落账，不绑死任何 Agent 平台 |

## 三条设计原则

### 1. 少设定，多留白
初始设定提供**起点**，不是终点。人物模型不追求"信息越多越真实" ——
过度设计会让她变成被作者控制的固定角色。未知、空白、尚未形成的兴趣与观点
都是刻意保留的。

### 2. 确定性优先于"聪明"
分类、关系判定、用户模型、行为审计**全部用可复现规则**，不用模型判定。
理由很实际：这套东西的价值在于**能回答"为什么这条被这样处理"**。
换成模型判定，就再也解释不清了。

### 3. 历史不可篡改
记忆版本、用户模型快照、关系快照都是 **append-only**。
被修正的条目**标记取代、绝不删除** —— "我为什么改了看法"必须永远可查。

## 快速开始

```bash
git clone <你的仓库地址>
cd <仓库名>
python -m venv .venv
.venv/Scripts/activate          # Windows
pip install -r requirements.txt
cp .env.example .env            # 填入自己的 API Key
python src/main.py ui           # 打开本地聊天界面
```

!!! note "首次运行是空的"
    本仓库**不含任何真实对话与记忆数据**。
    `conversation/`、`memory/`、`user_model/`、`self_model/`、`relationship/`
    都在 `.gitignore` 里，首次运行时由程序创建。

## 已知限制（如实列出）

- **原始事件表的 `sha256` 只是普通列，没有哈希链** ——
  同时改写 JSON、数据库与侧车文件即可通过校验。**未修。**
- **归档层在真实数据里长期为 0 条** —— 机制正确，但缺可归档的候选。
- **主动消息无法真推送** —— 只能等用户开口时随回复附上。
- **做不到无人值守长期运行** —— 项目没有调度器与常驻进程。
- **提示词注入面未做系统测试**。
- **`execute` 权限默认关闭**，开放等于允许模型在本机执行任意代码。
